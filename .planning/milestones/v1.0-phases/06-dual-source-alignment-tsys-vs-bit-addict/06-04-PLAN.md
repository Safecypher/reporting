<objective>
Make every figure on `/alignment` traceable. Add a two-level drill inside one continuously-open
Sheet — level one answers "when did we stop agreeing?" with a per-day breakdown for the metric, level
two answers "what exactly did each side record that day, and which uploaded file did it come from?" —
and the full-page day-breakdown route the capped Sheet links out to for long periods.

Purpose: ROADMAP SC4 is the difference between a dashboard that asserts a number and one that can
prove it. The Phase 3 drill stack was built generic for exactly this, so the work is new drill
entities and one new interaction mechanic (two levels in a single Sheet), not new machinery. The one
genuinely new capability is the source-file caption: the existing drill fetchers return the file
identifier but never its name, so the contributing rows currently cannot state where they came from.
Output: four whitelisted drill entities, a two-level Sheet, a new full-page route, and file-name
provenance on every contributing row.
</objective>
