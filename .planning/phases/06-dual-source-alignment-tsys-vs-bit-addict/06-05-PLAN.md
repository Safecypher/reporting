<objective>
Give the app a home. Replace `app/(dashboard)/page.tsx`'s redirect with a real dashboard landing page
carrying an **alignment status strip** that rolls the four metrics up into one worst-status-wins
verdict plus four per-metric mini-badges, and **three headline KPI tiles** — live cards, volume this
period, revenue this period — each linking to its canonical page.

Purpose: ROADMAP SC5 requires a genuine disagreement to be visible without opening the reconciliation
page, and today there is no home for it to be visible on. The strip is what makes that criterion true.
Two things must be right: the strip must never render an unearned green badge before any comparison
exists, because an unearned all-clear is exactly the failure this product exists to prevent; and each
region needs its own error boundary, because `error.tsx` is route-segment-scoped and would blank the
whole page — including the strip — when one tile's read fails.
Output: a real `/` route, a shared component-level error boundary, the rollup strip, three tiles, and
a Home nav entry with an active-route rule that highlights exactly one item.
</objective>
