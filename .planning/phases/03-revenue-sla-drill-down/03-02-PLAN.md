<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → Server Action | Untrusted FormData/JSON crosses into the server write path |
| Server Action → pricing tables | Session-scoped write; RLS + audit trigger enforce attribution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering / Elevation of Privilege | savePricingTierSet invoked directly with a manipulated tiers array | mitigate | Mandatory server-side pricingTierSetSchema.safeParse re-validation (client RHF is UX only); render-time gating is not a security boundary |
| T-03-06 | Spoofing | Attribution bypass by using the secret-key writer (no session user) | mitigate | Action uses session-scoped createClient so auth.uid() is present for the audit trigger; secret-key writer is explicitly forbidden (grep gate in Task 1 verify) |
| T-03-07 | Spoofing (CSRF) | Cross-site invocation of the pricing Server Action | accept | Next.js 16 enforces Origin/Host CSRF checks on all Server Actions by default; no app-level token needed |
| T-03-08 | Information Disclosure | Anon/unauthenticated write | mitigate | RLS insert policy is `to authenticated` only (from 03-01); action also short-circuits on missing user |
</threat_model>
