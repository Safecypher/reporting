<objective>
Build `/settings/sources`: the operator surface for per-source cadence, overdue threshold and
monitoring on/off.

Purpose: FRESH-05 and ROADMAP SC-5 — the thresholds must be adjustable without a redeploy.
D-13 requires audit, not restriction: any authenticated internal user may tune a threshold,
and every change is attributed and appended to a history nobody can edit.

Output: the new route, its Zod-validated per-row Server Action, the per-row table editor, the
`Switch` primitive, and the sidebar entry.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Server Action | `saveReportSourceSettings` is a directly-invocable untrusted entry point; anything the client sends is attacker-controlled. |
| Server Action → `report_sources` UPDATE → audit trigger | `auth.uid()` must be in scope for attribution; a privileged client would silently write a null actor. |
| shadcn CLI → `package.json` / `components/ui/` | A copy-in command that also installs a package introduces an unreviewed dependency. |
| browser → `report_sources` via PostgREST | Any authenticated user can read and UPDATE the table directly, bypassing the form. RLS, the CHECK constraints and the trigger are the controls, not the form. |
