## Task 3 — IN-03: answer the question, do not assume the answer

`types/db.ts:13` reads `PostgrestVersion: "14.5"`, down from `"14.15"` before the 05-05
regeneration. It survived a further regeneration on 2026-09-15 unchanged.

**This is a question, not a defect.** Both `14.5` and `14.15` are plausible PostgREST versions,
and `14.5 < 14.15` only looks like a regression under semver — lexically it is just a different
string. Determine the linked project's actual PostgREST version, then:

- If the project really is on 14.5, the file is correct. Record that, close IN-03 as
  "not a defect", and leave the file alone.
- If it is on 14.15 or later, re-run `supabase gen types typescript --linked > types/db.ts` and
  diff carefully — a regeneration at this point could also pick up 0039's `data_window_start()`
  and any drift accumulated since 09-15. Review the whole diff, not just line 13.

Do not edit the version string by hand under any circumstances. It is generator output; a
hand-edit makes the file lie about its own provenance.
