<interfaces>
Contracts this plan CREATES (Route Handler in Plan 05 consumes them):

  ReportType = 'verification'   // the only type wired in Phase 1

  interface IngestionInput {
    fileName: string;
    bytes: Uint8Array;        // raw uploaded bytes (server-side only)
    contentType?: string;
    uploadedBy: string;       // auth user id
  }

  interface RejectedRow { row: number; reasons: string[] }

  interface IngestionResult {
    reportType: ReportType | null;
    accepted: number;
    duplicates: number;
    rejected: number;
    rejectReasons: RejectedRow[];
    ingestedFileId: string | null;
    alreadyUploaded?: { date: string };   // set when content_sha256 already seen
  }

  // Injected dependencies keep ingest() pure/testable:
  interface IngestDeps {
    findFileByHash(sha256: string): Promise<{ id: string; uploaded_at: string } | null>;
    recordFile(meta): Promise<string>;             // insert ingested_files (pending) → id
    upsertVerifications(rows): Promise<number>;     // INSERT ... ON CONFLICT (row_hash) DO NOTHING RETURNING id; returns inserted count
    finalizeFile(id, counts): Promise<void>;        // UPDATE ingested_files status + counts
  }

  export async function ingest(input: IngestionInput, deps: IngestDeps): Promise<IngestionResult>;
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uploaded file bytes → parser | Uploaded content is untrusted; every row must be validated before it can reach the DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Malformed/malicious CSV rows | mitigate | Zod validates every row before insert; rejects with explicit per-row reasons; never silently coerces (INGEST-04, ASVS V5) |
| T-04-02 | Tampering | Wrong file disguised with .csv extension | mitigate | classify() rejects any file whose header signature does not match a known report; unrecognised → reportType null, no rows inserted |
| T-04-03 | Information Disclosure | Parsing on the client | mitigate | Parse logic is server-only (Node crypto + PapaParse on the buffer); this module is never imported under a 'use client' boundary |
| T-04-04 | Repudiation | Silent data loss | mitigate | Cutoff-excluded and rejected rows are counted and reported in IngestionResult, not dropped silently |
</threat_model>
