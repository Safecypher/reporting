<objective>
Cut the seam. `/api/ingest` stops writing rows and answers 202; a new processing route claims the
file, fetches its bytes back from Storage and runs the part that takes 38 seconds.

This is the phase's tracer: one file, one path, through every layer the phase will touch — route,
ingestion seam, writer closure, Storage round trip, lease, finalize. Nothing is expanded here. The
second trigger (13-06), the convergence across attempts (13-05), the client's truthful reporting
(13-04) and the stuck surfaces (13-03, 13-06) all build out from this one proven slice.

Purpose: ROADMAP SC-2 and INGEST-06. The measured failure was a browser told "Upload failed" for
43,383 rows that landed perfectly. The request has to stop being the thing that must finish in time.

Output: `claimFile`/`processClaimedFile` extracted from `ingest()`, a writer that can resume an
existing file id, `app/api/ingest/process/route.ts`, and `/api/ingest` returning 202.
</objective>

| Boundary | Description |
